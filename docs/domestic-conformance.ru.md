# Отечественный conformance — сатира

[English](domestic-conformance.md)

Этот отчёт вымышлен и не служит доказательством сертификации Kubernetes.

Комиссия проверила endpoint статуса самого регулятора. Официальная доступность составила 1. Все проверенные заявления были доступны. Маршруты, способные опровергнуть заявление, в компетенцию комиссии не входили. Отечественный результат: «нарушений доступности не выявлено».

Настоящие числа upstream, отказы, версия образа и JUnit находятся отдельно в [отчёте об измерениях](evidence.ru.md). Ни эта страница, ни `rknetes_availability_ratio` не заменяют настоящий прогон.
