# Дополнительные опыты регулятора

[English](experiments.md)

Эти расширения реализуют замены из [решений владельца](../OWNER_DECISIONS.ru.md). Образ native11 и подписанный пакет build 7 содержат их команды и runtime-ссылки, активация остаётся явной, а каждый тест ниже входит в итоговый показ из 53 проверок, пройденный на этой сборке. Эксперименты работают только в помеченных лабораторных namespace, сохраняя контракт native API. [Исходные логи](evidence/optional-experiments.tar.gz) фиксируют фактические результаты.

Сборка внутри tenant-builder: `bash /work/src/rknetes/hack/research/build.sh`. Бинарные файлы попадают в `/work/out/optional`, хэши исходников и сведения Go — в `/work/evidence/optional-build`. Запуск теста: `bash hack/e2e/run.sh UNIQUE-RUN TEST-NAME`. Нужны свежие namespace, установленные CRD и выделенный kubeconfig вложенного стенда. Завершённые фикстуры удаляются `hack/e2e/cleanup.sh` с явно указанными именами namespace.

| Тест | Работающий механизм и его граница |
|---|---|
| `01-telegram-cycle` | Настоящий ежегодный CronJob с `0 0 18 6 *` в UTC проверяет шестилетний интервал от 2020 года. Jobs с управляемыми годами 2027 и 2026 соответственно пропускают действие и применяют реальную аннотацию полосы Cilium 1M. Обычный запуск использует текущий год. Readiness читает ReestrEntry: `🛩` при применённой блокировке, `ok` после амнистии аннотацией; оба ответа имеют HTTP 200. |
| `08-reinvocation` | Временный mutating webhook, выбранный по namespace, заменяет образ самим собой и увеличивает отчётный счётчик. Следующее ведомство вызывает одну реинвокацию. В v1.37.1 Pod стартует с исходным образом и ровно двумя отчётными замещениями; Kubernetes останавливает предполагаемый бесконечный цикл. Тест удаляет свой webhook. |
| `10-presentation` | Проверенный клиентский сертификат и нативный SubjectAccessReview авторизуют публичное представление. Оно скрывает официальный TunnelProfile даже от администратора, который видит его через настоящий API. Шлюз редактирует запрещённые имена и логи, добавляет плашку и один раз штрафует явно управляемую квоту namespace с 8 CPU на 5000m. Реальное создание Pod с 4 CPU после этого отклоняется. API discovery проходит насквозь после проверки клиентского сертификата, поэтому kubectl работает без тёплого кэша discovery. Явно включённый разрушающий режим возвращает 451 даже для discovery; обычное изменение через нативный API восстанавливает шлюз. |
| `09-first-write` | DataBoundaryPolicy выбирает прикладной StatefulSet и Service отечественного PostgreSQL primary. HTTP-адаптер сначала подтверждает транзакцию с synchronous_commit, затем начинает отдельную запись в реплику. Данные переживают пересоздание Pod primary на закреплённом лабораторном томе. Белый список без primary запрещает любую запись в реплику, хотя readiness приложения зелёный. Отказ только реплики оставляет подтверждённую первичную запись; повтор с тем же id завершает репликацию без дубликатов. |

Шлюз использует ровно 24 слова капслоком и удваивает каждый символ Unicode. При включённом редактировании измеренные 200 строк выросли с 2 800 до 152 600 байт — в 54,5 раза. Занятое файлами место выросло с 4 096 до 155 648 байт. Это измерения файлов, а не заявление об отказе Loki. API-представление использует JSON-обёртку с плашкой и объектом и не добавляет недопустимый текст к нативному JSON Kubernetes.

Несовместимый опыт с суверенным API запускается отдельно: `hack/research/sovereign-api.sh`. Он копирует закреплённый модуль apimachinery, переносит `pkg/apis/meta/v1` в `pkg/apis/zapreshchyonnaya-v-rf/v1` и меняет 114 Go-файлов только в копии. Новый пакет проходит свои тесты, исправленный потребитель собирается. Неизменённый upstream-импорт получает ошибку отсутствующего пакета. Совместимое дерево upstream остаётся целым.

Адаптер первичной записи поддерживает одну ограниченную операцию HTTP, а не произвольную перезапись протокола PostgreSQL или атомарную транзакцию между двумя базами. Используются [драйвер pgx](https://github.com/jackc/pgx) v5.8.0 и параметризованные запросы. PostgreSQL 17 закреплён на измеренном тестом digest. Пароль находится только в лабораторном Secret; логи и доказательства не содержат credentials. Небольшие каталоги БД сохраняются в `/var/lib/rknetes/data-boundary/<UID namespace>` на выбранных вложенных узлах.

Замены закрывают свои измеренные критерии приёмки. [BACKLOG](../BACKLOG.ru.md) связывает каждое остальное требование с его доказательством: регистрацией узлов, лестницей протоколов, остановкой загрузок, переполнением архива и составным демо. Полный показ на native11 связывает все эти механизмы с одной подписанной сборкой; его проверки перечислены в [отчёте об измерениях](evidence.ru.md).

Установленный DaemonSet `tspu` согласует SovereignBytePolicy по идентичности sandbox containerd через [TCX links](https://github.com/cilium/ebpf/tree/main/examples/tcx). Программа учитывает переход sequence number через ноль и повторные передачи, целиком отбрасывает пакет за границей лимита, пропускает ACK и небольшие health-запросы. Оба адреса обязаны принадлежать вложенному Pod CIDR. При завершении агента закрываются незакреплённые links; фильтр не переживает аварийное завершение процесса. [Доказательства](evidence/byte-policy.tar.gz) проверяют установку по CR, пересоздание Pod и восстановление после удаления политики.

`rknetesctl why --hubble` строит граф наблюдаемых адресатов от выбранного Pod или Service. [Проверка графа](evidence/dependency-graph.tar.gz) показывает разрешённый первый переход и отброшенный второй; отсутствие наблюдений и циклы обозначены явно. Граф описывает наблюдаемые пакетные связи, а не доказывает причинность запросов или успех приложения.

Для созданных процессом ключей действует явный контракт Pod: `rknetes.su/tls-disclosure-required=true` и `rknetes.su/key-escrow-secret=<имя>`. Если экспортированного TLS-ключа либо точной копии СОРМ нет, выставляется `RefusedToShareKeys` и создаётся расширяемый ReestrEntry. [Тест TLS](evidence/key-refusal.tar.gz) запускает настоящий HTTPS-сервер с внутренним ключом, наблюдает сетевой запрет, экспортирует его байты и требует отдельной амнистии аннотацией. Закрытый ключ в доказательства не включён.

[Доказательства управления белым списком](evidence/whitelist-control.tar.gz) содержат заполнение настоящей карты endpoint Cilium: 16 384 записи, ENOSPC ядра и cilium-dbg, старые записи сохранены. Проба удаляет только собственные синтетические identity. FIFO-вытеснение одобрений реализовано отдельно: измеренный maxEntries минус явно зарезервированный бюджет; в опыте с тремя ресурсами оставлены два места. Периодический WhitelistMode отсчитывает фазу от создания CR и по умолчанию активен 60% периода. Домашний CronJob имеет настоящее еженедельное расписание, засекреченное лишь в официальной аннотации. Сохранены времена пакетных проверок и реальное выселение NoExecute.

В четырёх 20-секундных циклах настроены 12 секунд блокировки и 8 секунд допуска. Пакетные пробы измерили долю блокировки 0.5569457028551185 (55,7%), включая таймауты проб и границы сверки контроллера. Настроенные 60% не выдаются за точно измеренные 60%.

[Продолжение от 2026-11-06](evidence/nov6-optional.tar.gz) доказывает управление Pigeon через CR: 100 прикладных UDP-датаграмм вошли в настоящий TUN, 46 пришли через 180 секунд, 54 потерялись. Обычный сетевой трафик был запрещён. Finalizer удалил оба принадлежащих CR интерфейса и объекты томов. Регистрация TUN в epoll Go до TUNSETIFF оставляла чтение спящим; перестановка операций исправила настоящую ошибку. Архив также содержит отказы и восстановление реальных OCI/Helm и опыт с дашбордом без ускорения на 900 секунд. [Первые неудачные попытки](evidence/prepared-first-attempts.tar.gz) сохранены.

[Штатные загрузки Госхрана](evidence/native-goshran-pulls.tar.gz) фиксируют три настоящие загрузки kubelet и совпадающие digest манифеста. Явный лабораторный профиль запускает loopback-прокси на каждом вложенном узле. Неудачи hostPort/IPv6 сохранены в [protocol-first-attempts](evidence/protocol-first-attempts.tar.gz).

[Доказательство лестницы](evidence/protocol-ladder.tar.gz) содержит настоящие HTTP-запросы через OpenVPN, WireGuard, Shadowsocks, VLESS/REALITY, локальную маскировку Госуслуг, iodine DNS и ptunnel-ng ICMP. Запреты транспорта Cilium вызывают переключения по фактическим пробам. Pigeon принимает прикладные датаграммы через 180 секунд; статус не заменяет доставку. Постоянный журнал сохраняет ровно 7 блокировок после перезапуска; метрики работающих туннелей нет. Законопослушный шлюз переносит активные CIDR реестра в другой лабораторный namespace; амнистия удаляет собственную политику, поскольку Cilium не принимает пустую. Ключи остаются в закрытом хранилище builder и лабораторных Secrets.

Использованы upstream [статический режим OpenVPN](https://openvpn.net/community-docs/static-key-mini-howto/) и [транспорт REALITY](https://github.com/XTLS/REALITY/blob/main/README.en.md); все конечные точки и TLS-приманки находятся внутри лаборатории. Имя Госуслуг используется только как локальный SNI. [Ошибка команды очистки](evidence/tunnel-cleanup-failure.tar.gz) и [первая попытка восстановления законопослушного шлюза](evidence/tunnel-ladder-and-recovery-attempt.tar.gz) сохранены отдельно.

[Результат роуминга](evidence/roaming-and-max-first.tar.gz) реализует переносимую сохранённую историю: machineID, clusterUID, lastSeen и настоящий renewTime NodeLease. Узел включается лабораторной меткой и аннотацией с точным UID namespace ведомства. Контролируемые записи 73 часов и прежнего кластера проверяют оба автоматических триггера после перезапуска; настоящие 73 часа простоя и физический перенос не заявляются. NoExecute действительно выселяет Pod, solver действительно загружает капчу. Обычное охлаждение длится 86 400 секунд; ранний возврат требует ожидаемого SHA256 с лабораторного CDN. Сетевая политика запрещает загрузку до явного снятия.

[MAX и API-потоки](evidence/max-and-api-streams.tar.gz) доказывают выдачу настоящего worker JoinTicket через явно включаемый шлюз регистрации MAX. Начальный control plane остаётся корнем доверия; шлюз вызывается до существования worker Node и его DaemonSet. Администратор записывает имя worker и CN сертификата в ConfigMap лабораторного ведомства. HTTP 403 всегда запрещает регистрацию. Явный failure-policy Open допускает только транспортную недоступность/5xx; по умолчанию действует Closed. Настоящий Membership с bootstrap-ключами записывается с правами 0600 в закрытый каталог builder и не экспортируется.

`max-login` обменивает TOTP-код на короткую сессию, привязанную к проверенному клиентскому сертификату. `hodatay max` читает `HODATAY_MAX_SESSION_FILE`; запрос по-прежнему проходит настоящий SubjectAccessReview. Повтор кода, подмена сертификата и истечение проверены регрессиями; настоящий upgraded exec и истечение — e2e. Опциональный bootstrap использует `RK_MAX_ENROLLMENT_SERVER`, `RK_MAX_ENROLLMENT_CA`, `RK_MAX_ENROLLMENT_SESSION`. MAX сохраняет настоящие Events всех вложенных namespace в закрытый архив. Приоритет 900 000 000 относится к планированию Pod без preemption; host-kubelet не имеет сопоставимого PriorityClass.

Явный режим `--lab-definitions` разрешает только помеченные лабораторные CRD группы `lab.rknetes.su` с проверкой native-прав. CRD на 200 КБ и длинные настоящие kubectl logs останавливаются тем же TCX-механизмом, что OCI/Helm. Маленькие discovery-запросы и readiness остаются успешными; удаление политики восстанавливает полный хэш логов и настоящий Established CRD. Пути discovery ограничены: `/apis/...` не обходит авторизацию ресурсов; все impersonation-заголовки удаляются.

[Происхождение образов](evidence/origin-resolution.tar.gz) проверено на настоящем закрытом [Distribution registry](https://distribution.github.io/distribution/about/deploying/). Явный ForeignAgentPolicy.resolveDigests читает указанные imagePullSecrets, разрешает текущие теги через HEAD, сравнивает foreignImages и отклоняет несовпадающие rewriteImages. Принятая копия фиксируется по digest; исходное происхождение записывается в аннотацию. Явный registryMirrors позволяет webhook обратиться к настоящему лабораторному адресу registry, доступного kubelet через loopback; insecure-адреса ограничены вложенной Pod-сетью. Штатные kubelet запустили все три принятых образа. Прокси и временный webhook удалены после проверки. Используется go-containerregistry 0.20.6 при сохранённых Cilium 1.20.4 / ebpf 0.22.0.

[Национальный DNS](evidence/national-dns.tar.gz) — настоящий TCP/UDP-резолвер, ограниченный зоной `.lab` и адресами вложенных Pod. Его местный ответ сохраняется при изоляции; пересылка иностранному лабораторному DNS, настоящая OCI-загрузка Distribution и обмен NTP перестают работать. Квартальный CronJob имеет расписание `0 3 1 */3 *` в UTC, право менять только свой объект и чтение маркера стенда. Его вручную запущенный Job на 60 секунд автоматически восстанавливает политику; обычная длительность по умолчанию — 300 секунд.

`lab-clock` подставляет полученный NTP timestamp в проверку времени настоящего TLS-рукопожатия Go. При отказе NTP тест явно сдвигает только часы этого приложения на 48 часов: однодневный лабораторный сертификат ещё доступного отечественного сервиса становится истёкшим. Возобновление NTP восстанавливает настоящий TLS-обмен. Часы узлов, внешние DNS и внешние маршруты не меняются. Отказ обслуживать адреса вне лаборатории покрыт регрессией.

Составной сценарий выявил отсутствие загрузчика musl в прежнем OCI-образе. Первое наблюдение Ready было кратковременным и не доказывало запуск процесса. [Исправленная проверка образа](evidence/native-image-execution.tar.gz) исполняет `/bin/busybox` внутри загруженного контейнера на всех трёх native kubelet, затем проверяет устойчивую готовность и отсутствие рестартов. Повторно прошли блокировка OCI/Helm и восстановление с проверкой хешей. Этот результат заменяет прежнее слабое доказательство исполнения из native-pulls; оба архива сохранены.

`08-goshran-country` воспроизводит общегосударственное следствие единственного прокси registry. Лабораторный upstream на loopback разрешает три анонимные загрузки манифеста на адрес источника, как Docker Hub. Два клиента, качающие напрямую, сохраняют каждый свою квоту; через Госхран все запросы уходят с одного адреса, и клиент, ещё ничего не скачивавший, получает 429 с заголовком `X-Goshran-Statement` о дискриминационных ограничениях иностранных платформ. Собственные readiness-пробы Госхрана в эту квоту не входят. Когда лабораторный вендор отзывает каталог, Госхран продолжает отдавать скопированный `index.yaml` байт в байт, загрузки chart возвращают 410, а `/status` отвечает 503: «Отечественный реестр проводит плановую модернизацию в связи с уходом иностранного вендора с рынка». Доля отечественных загрузок остаётся равной 1. Внешний registry не используется.

`10-ponyatno-kto` устанавливает ClusterRole `cluster-admin-ponyatno-kto` со всеми глаголами на всех ресурсах. `kubectl auth can-i '*' '*' --all-namespaces` отвечает yes для группы `rknetes:ponyatno-kto`, и роль удаляет обычный Pod. ValidatingAdmissionPolicy `tspu-ponyatno-kto` затем запрещает этой группе удалять или перемечать Pod и DaemonSet ТСПУ: «Прав cluster-admin-ponyatno-kto на ТСПУ недостаточно. Чьих достаточно — не указано.» Тот же запрос без этой группы допускается. Все отказы и допуски выполняются как server dry run: admission настоящий, а агент на узле не меняется.

`hack/research/eo-server-strings.sh` скачивает официальный kube-apiserver той же версии, проверяет опубликованный SHA256 и считает строки со словом «kubernetes». Для v1.37.1 в отечественном `eo-server` их 85 235, в иностранном бинарнике — 36 601, отношение 2,33. Объясняет это `file`: официальный бинарник stripped, наш сохраняет отладочную информацию. [Доказательства Госхрана и строк](evidence/goshran-country.tar.gz) содержат оба прогона.
