# Шаблоны заявления в реестр

[English](README.md)

Это подготовительный комплект для РКНетеса; он никуда не подан. Он не утверждает включение в реестр российского ПО, наличие сертификации, соответствие неизвестного правообладателя требованиям или исключительные права на исходный Kubernetes.

РКНетес — модификация и дистрибутив Kubernetes под Apache-2.0 на базе kuberoot, с дополнительными Go-контроллерами, admission-сервисами, CLI и изолированными сетевыми экспериментами. Собственный код распространяется под Apache-2.0. Linux и сторонние зависимости сохраняют свои лицензии. Утверждения «разработано с нуля» и «отечественный conformance» относятся к сатире и исключены из заявления.

Заявитель заполняет [application.ru.md](application.ru.md), прикладывает доказательства из [rights-and-components.ru.md](rights-and-components.ru.md) и уточняет [operations.ru.md](operations.ru.md) по фактической поставке и поддержке. Пустые поля обозначены явно. Описание продукта включает только измеренные возможности и приложенные результаты проверок.

Исходный нормативный акт — постановление Правительства РФ от 16.11.2015 № 1236. Применять следует действующие правила, а не исходное название о запрете закупок. В [официальном каталоге документов реестра](https://reestr.digital.gov.ru/documents/) перечислены № 1236, классификатор по приказу от 22.09.2020 № 486 и изменяющее постановление от 28.11.2025 № 1937. [Официальная публикация № 1937](https://publication.pravo.gov.ru/document/0001202512080042) — отдельный источник от [исходной страницы № 1236](https://government.ru/docs/20650/).

Проверка источников 06.11.2026: официальный каталог доступен в индексированных выдержках, прямое скачивание снова завершилось таймаутом. Согласованный владельцем [датированный обзор](rules-review.ru.md) ссылается на актуальную вторичную сводную редакцию 2026-08-13 и постановление № 1007. Объём шаблона этим выполнен; перед будущей подачей заявитель получает первичный текст, проверяет даты и применимость. Данные правообладателя остаются явными полями для заполнения.

Учётные записи не использовались, заявление не подписывалось, документы не отправлялись и не публиковались.

Вторичный [индекс действующей редакции](https://www.consultant.ru/document/cons_doc_LAW_189116/92d969e26a4326c5d02fa79b8f9cf4994ee5633b/) указывает изменение № 1007 от 13.08.2026. Это ориентир для поиска полного официального текста, а не замена его проверки.

[Проверка действующих правил и границы шаблона](rules-review.ru.md) фиксирует повторную проверку источников 06.11.2026. B30 закрыт в согласованном объёме шаблона; проверка первичного текста перед будущей подачей остаётся обязанностью заявителя.
