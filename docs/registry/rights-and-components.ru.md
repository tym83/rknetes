# Права и состав компонентов

[English](rights-and-components.md)

Приложить договоры или доказательства авторства собственных изменений РКНетеса и перечень изменений файлов относительно закреплённых исходных ревизий. Переименование репозитория, перевод интерфейса, тег образа, место кэша или зеркало исходников не доказывают самостоятельное авторство и не передают исключительные права исходных разработчиков.

| Компонент | Происхождение / лицензия | Доказательство |
|---|---|---|
| Контроллеры и CLI РКНетеса | Этот репозиторий / Apache-2.0 | Коммит релиза, архив, LICENSE, перечень собственных изменений |
| Kubernetes | kubernetes/kubernetes / Apache-2.0 | Закреплённый тег, исходные уведомления, патч, хэши бинарников |
| kuberoot | kuberoot-dev/kuberoot | Ревизия, исходная лицензия и уведомления, профиль дистрибутива |
| Cilium и eBPF | cilium/cilium и этот репозиторий | Версии, лицензии конкретного кода, дайджесты chart и образов |
| Linux | kernel.org / GPL-2.0-only с применимыми исключениями | Точные исходники, конфигурация и соответствие поставленному ядру |
| containerd, runc, CoreDNS, etcd, Helm, Go-модули | Исходные проекты | Версии и исходные лицензии |
| Тестовые образы и зависимости Helm | Каждый исходный артефакт | Registry, digest, цепочка редиректов, хэши архивов chart |

Фактический состав формируется из сборки: `go list -m -json all`, контрольные суммы модулей, исходники и конфигурация ядра, хэши бинарников узлов, версия Cilium chart, imageID подов. Включить транзитивные зависимости и обязательства предоставления исходников поставляемых copyleft-компонентов. Сохранить copyright, тексты лицензий и применимое содержимое NOTICE; скрипт переименования их не заменяет. Условия распространения приведены в [Apache-2.0](https://www.apache.org/licenses/LICENSE-2.0).

Правообладатель заполняет [РЕЕСТР ВЫПЛАТ], [ЦЕПОЧКУ ВЛАДЕНИЯ], [ДОГОВОРЫ РАЗРАБОТКИ], [ПРОВЕРКУ ЛИЦЕНЗИЙ]. Эти факты не выводятся из наличия исходного репозитория.


Итоговая [инвентаризация native-образа](../evidence/inventory-final.tar.gz) содержит 4 201 экземпляр и 1 351 различную тройку имя/версия/тип. [Приложение лицензий](../evidence/licences-final.tar.gz) закрывает все 1 026 пропусков сканера: 754 тройки, 397 различных текстов доказательств, 526 проверок h1 архивов модулей. Лицензии не объединяются: у Grafana действует AGPL, у Linux есть обязательства GPL, а npm-ссылки из lockfile телеметрии Go не означают установленный JavaScript runtime. У сгенерированных SDK Parca отсутствует корневой файл лицензии; приложение сохраняет точные уведомления схем и лицензии генераторов с явным указанием этой границы. Сканер не выдаёт юридического заключения.

Все сравнённые native/builder-бинарники совпадают. [Повторная сборка](../evidence/repeat-build.tar.gz) охватывает все команды RKNetes из разных каталогов исходников. [Доказательства Kine](../evidence/kine-provenance.tar.gz) заменяют прежний dirty-бинарник точным upstream 35f4319798cf3543e49f86c775a1f8c5c23b1e80, чистым деревом и двумя одинаковыми сборками. Воспроизводимость timestamps rootfs и каждого импортированного upstream-бинарника этим не утверждается. Приложены Kubernetes patch, закреплённая база, Go inventory, kernel config и хеши артефактов. Старые материалы native6 остаются историческими доказательствами.
