# Датированная проверка правил

[English version](rules-review.md)

Проверено 2026-11-04. [Официальный каталог](https://reestr.digital.gov.ru/documents/) указывает постановления 1236, 1937 и классификатор № 486. Прямая загрузка каталога/PDF вновь завершилась таймаутом; владелец разрешил датированные вторичные источники для шаблона.

[Вторичная сводная редакция от 09.12.2025](https://www.kontur-extern.ru/info/normativ/document/1/504756-postanovlenie-pravitelstva-rf-ot-16-11-2015-n-1236) предусматривает проверку прав/контроля, иностранных выплат, размещения поддержки/сборки и совместимости с доверенными ОС. Пункт 5(м) обычно требует две доверенные ОС с оговорёнными исключениями. Заявитель указывает применимое исключение либо прикладывает испытания совместимости; стенд kuberoot не доказывает выполнение этого требования или допустимость включения.

[Постановление № 1007 от 13.08.2026](https://www.kontur-extern.ru/info/normativ/document/1/508442-postanovlenie-pravitelstva-rf-ot-13-08-2026-n-1007) действует с 01.09.2026 и добавляет признак соответствия стандартам для указанных государственных информационных систем. RKNetes не выдаёт такой сертификат.

Перед будущей подачей заявитель получает действующий первичный текст, сверяет последующие изменения, выбирает класс продукта и заполняет все поля о частных фактах. Подача не входит в задачу. Результат — согласованный владельцем шаблон без отправки.
