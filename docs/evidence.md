## New regulator mechanisms

`08-goshran-country` gives the country one upstream address. A lab registry allows three anonymous pulls per source address: six direct pulls from two addresses all succeed, while the same pulls through Goshran exhaust one shared quota, and a client that never pulled before receives 429 with the `X-Goshran-Statement` press release. When the lab vendor withdraws its catalogue, Goshran keeps serving the copied `index.yaml` byte for byte, chart downloads fail and `/status` returns 503 announcing «плановую модернизацию» in connection with the vendor's departure.

`10-ponyatno-kto` installs ClusterRole `cluster-admin-ponyatno-kto` with every right; `kubectl auth can-i '*' '*'` answers yes and the role deletes ordinary Pods. ValidatingAdmissionPolicy `tspu-ponyatno-kto` refuses any change to the TSPU agent from group `rknetes:ponyatno-kto`, stating that whose rights suffice is not specified. The identical request without that group is admitted. Every refusal and admission uses server dry run, so the node agent itself never changes.

`hack/research/eo-server-strings.sh` downloads the official kube-apiserver v1.37.1, verifies its published hash and counts strings containing “kubernetes”: 85,235 in the domestic `eo-server` against 36,601 in the foreign binary. `file` explains the gap: our build is not stripped and keeps its debug information. Both outputs are in [the Goshran and strings archive](evidence/goshran-country.tar.gz).

The presentation gateway now passes API discovery through once the client certificate is verified (commit `949c9d9`); resource reads keep every check. `09-first-write` waits until the reinstalled whitelist policy exists before the partial-replication write.

## Failed final attempts

Two earlier final candidates are kept in [final-attempts-native10](evidence/final-attempts-native10.tar.gz). Native9's package build 5 took its runtime image from a running Pod's `imageID`. After the import-substitution tests the node knew that digest under the lab loopback name of the `domestic/shop` image, so the chart shipped an image only one node could pull. The image is now pinned in `hack/package/runtime-image.ref`. On native10 kubepkg correctly refused to republish build 5 with different content, and the chart moved to build 6. Its tour `demo-final-2` passed 51 of 53: `18-composed-shop` received HTTP 400 from presentation discovery, which earlier runs had hidden behind a warm kubectl discovery cache, and `09-first-write` raced the reinstalled whitelist. Both fixes are in native11. [The native9 inventory](evidence/inventory-final.tar.gz) and its [licence supplement](evidence/licences-final.tar.gz) remain with them.
