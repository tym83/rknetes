# Результаты измерений

[English](evidence.md)

На трёхузловой нативной сборке 04.11.2026 завершён `demo-native-1`: **19 проверок успешны, отказов нет**. Лог и код завершения каждого скрипта находятся в [сохранённом архиве](evidence/demo-native-1.tar.gz). Они доказывают перечисленные механизмы, а не все подробности соответствующего контура. Остальные требования указаны в [BACKLOG](../BACKLOG.ru.md).

|---|---|---|
| 1 | `01-reestr.sh`, `01-self-block.sh` | Настоящий deny IP, переиспользование Cilium IPAM, BornBlocked и амнистия; маршрут контроллера к API получает timeout, восстанавливается отдельным маршрутом. |

| 5 | `05-pigeon.sh` | Из 100 корректных IPv4/UDP-датаграмм через хранилище при запрете сети доставлены 44, потеряны 56, с полной задержкой 180 секунд. |

После проверок контроллер создал итоговый StatusStatement; он прочитан из API. Потоковое соединение ноутбука прервалось, но удалённый запуск завершился; все 19 сохранённых кодов проверены отдельно. Перед conformance удалены явно помеченные лабораторные объекты и освобождены IPAM-резервы.

Нативный bundle: `kuberoot-0.1.0-dev-amd64.tar`, SHA256 `6192c30892c72c760043bc665c6bc3b93a4239f464026207c6f57077e08dda53`. Bundle подписан, закрытые ключи исключены. Kubernetes v1.37.1, upstream-коммит `f78e722310e50bcaca9276be22276d9e91d91308`, изменённое дерево. Cilium 1.20.4, ядро 6.18.55-kuberoot, containerd 2.4.1.

Состояние conformance: идёт run3 с официальным образом `registry.k8s.io/conformance:v1.37.1`, всеми 462 выбранными conformance-тестами и восемью процессами Ginkgo. После сбора JUnit здесь будет фактический результат. Run1 остановился при выборе credentials до создания ресурсов. Run2 намеренно прерван после обнаружения игнорируемого числового параметра параллельности. Ни один из них не считается успешным conformance.

«Отечественный conformance» — сатира. Лабораторные измерения не заявляют сертификацию или включение в реестр.
