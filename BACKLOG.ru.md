# Оставшиеся требования спецификации

[English](BACKLOG.md)

Концепция остаётся спецификацией. Успешный основной опыт не закрывает каждое предложение соответствующего контура. Ниже указаны отсутствующее доказательство либо противоречие, причина открытого состояния и критерий завершения. Эти возможности не выдаются за поставленные.

Сохранены временные отметки, пакетные пробы и итоговый ReestrEntry. |
| B02 (закрыт) | Ежегодный цикл Telegram и readiness-самолётик | 01-telegram-cycle проверяет настоящий CronJob, шестилетнюю проверку года, реальную аннотацию полосы и HTTP readiness по реестру. Принятая владельцем замена описана в docs/experiments.ru.md. |

[Решения владельца](OWNER_DECISIONS.ru.md) определяют замены для B02, B06, B12–B15 и B21–B23: сохранять шутки, реализуя явно названные работающие механизмы. Для шаблона реестра приняты поля правообладателя и датированные вторичные источники при таймаутах официальных загрузок; первичный текст сверяется перед подачей. Решения не отменяют перечисленных инженерных критериев приёмки.
