## 2026-11-04 — концепция и измеренная семантика Kubernetes

Сохранять каждую шутку. Не вычёркивать механизм из концепции: реализовывать честную работающую замену и описывать её в проектной документации как часть шутки. Ограничения, которые Kubernetes накладывает на регулятора, сами по себе смешны. Измеренное поведение записывать в доказательства.

| Пункт | Решение |
|---|---|
| B02 Цикл Telegram | Ежегодный CronJob с проверкой года: срабатывает каждый шестой год. Readiness `🛩` зависит от настоящего состояния реестра. |
| B06 Вытеснение белого списка | Измерить поведение Cilium при переполнении policy map. Вытеснение банка «Детским миром» реализовать очередью допуска поверх карты, с размером по измеренному лимиту. Не приписывать ядру выдуманное вытеснение. |
| B12 Невидимый официальный туннель | Отдельный фильтрующий API-шлюз скрывает официальный TunnelProfile от «публики». Настоящий API остаётся наблюдаемым — в этом и шутка. |
| B13 MAX на каждом узле | Регистрация узла через kuberoot JoinTicket требует регистрации MAX. Определить и проверить поведение при отказах. Второй фактор kubectl проходит через MAX-шлюз. Утверждение о приоритете заменить реально обеспечиваемым свойством. |
| B14 Плашка иноагента | Прокси логов/представления либо обёртка процесса добавляет удвоенную плашку из 24 слов. Измерить увеличение объёма и расход хранилища. API получает плашку только через путь представления, без повреждения JSON. |
| B15 Переименование metav1 и бесконечное импортозамещение | Отдельная намеренно несовместимая «суверенная сборка» переименовывает пакет и показывает последствия. Измерить ограниченную реинвокацию admission: один повтор, затем цикл останавливает закон Kubernetes. Отчёт считает каждый проход «замещённым компонентом». |
| B21 Первичная запись | Конкретный адаптер Postgres: сначала подтверждённая запись на отечественный primary, затем репликация. Проверить отказ записи при блокировке primary. |
| B22 ТСПУ и 451 | Явно включаемый разрушительный профиль шлюза возвращает 451 на всё. Проверить отказ для администратора и восстановление. Профиль по умолчанию сохраняет conformance. |
| B23 Национальный DNS и учения | Лабораторный resolver, управляемые часы и фикстуры NTP/registry только внутри tenant. Ограниченный эксперимент с истечением сертификата. |
